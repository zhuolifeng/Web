======== 7. EXPLAIN ANALYZE 实际耗时：走索引 vs 全表扫描 ========
mysql> EXPLAIN ANALYZE SELECT * FROM books WHERE category = '科幻' AND price BETWEEN 50 AND 100
-> Index range scan on books using idx_category_price over (category = '科幻' AND 50.00 <= price <= 100.00), with index condition: ((books.category = '科幻') and (books.price between 50 and 100))  (cost=1174 rows=2609) (actual time=0.0379..9.14 rows=2609 loops=1)


mysql> EXPLAIN ANALYZE SELECT * FROM books IGNORE INDEX (idx_category_price) WHERE category = '科幻' AND price BETWEEN 50 AND 100
-> Filter: ((books.category = '科幻') and (books.price between 50 and 100))  (cost=10229 rows=1220) (actual time=0.0428..75.5 rows=2609 loops=1)
    -> Table scan on books  (cost=10229 rows=98841) (actual time=0.0378..67.3 rows=100000 loops=1)
