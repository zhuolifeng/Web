二、Spring Boot 工程分层架构说明
================================================================

请求自上而下流转：

    HTTP 请求
        │
        ▼
   ┌────────────────────────────────┐
   │  Controller 表现层             │  接收 HTTP、做参数校验、组装响应
   │  /api/v1/users/register        │  UserController.java
   │  /api/v1/books                 │  BookController.java
   │  /api/v1/book/{id}             │
   └────────────────────────────────┘
        │   调用业务方法
        ▼
   ┌────────────────────────────────┐
   │  Service  业务层               │  事务、业务规则（如用户名查重）
   │  UserService.java              │  @Transactional
   │  BookService.java              │
   └────────────────────────────────┘
        │   调用 Repository
        ▼
   ┌────────────────────────────────┐
   │  Repository 数据访问层         │  Spring Data JPA，免实现 SQL
   │  UserRepository extends        │
   │      JpaRepository<User,Long>  │
   │  BookRepository extends        │
   │      JpaRepository<Book,Long>  │
   └────────────────────────────────┘
        │   ORM 映射
        ▼
   ┌────────────────────────────────┐
   │  Entity 实体层                 │  @Entity 映射数据库表
   │  User (users 表)               │
   │  Book (books 表)               │
   └────────────────────────────────┘
        │   JDBC
        ▼
       MySQL  (数据库 bookstore)

横切层：
  • dto/         —— 入参 (UserRegisterRequest) + 出参包装 (ApiResponse)
  • exception/   —— BusinessException + @RestControllerAdvice 全局异常
  • config/      —— WebConfig 配置 CORS，允许前端 :3000 调用后端 :8080

三、数据库设计
================================================================

数据库：bookstore  (CHARSET=utf8mb4)

users 表：
    id           BIGINT  PK auto_increment
    username     VARCHAR(64)   UNIQUE NOT NULL
    password     VARCHAR(128)  NOT NULL
    email        VARCHAR(128)  UNIQUE
    phone        VARCHAR(32)
    nickname     VARCHAR(64)
    created_at   DATETIME

books 表：
    id              BIGINT  PK auto_increment
    title, author, category, badge, stars
    rating_num, rating_count
    price, original_price
    description, intro, author_bio  (TEXT)
    publisher, publish_date, pages, isbn, binding
    cover_img, cover_emoji

启动时 schema.sql 自动建表、data.sql 自动插入 8 条样例（与前端 Data.js 一致）。


================================================================
四、启动步骤
================================================================

1) 启动 MySQL，并执行：
       CREATE DATABASE IF NOT EXISTS bookstore DEFAULT CHARACTER SET utf8mb4;

2) 修改 backend/src/main/resources/application.properties 中：
       spring.datasource.username=你的用户名
       spring.datasource.password=你的密码

3) 启动后端：
       cd backend
       mvn spring-boot:run
   监听 http://localhost:8080

4) （可选）启动前端：
       cd frontend
       npm install
       npm start
   访问 http://localhost:3000

五、Postman 测试用例
================================================================

【接口 1】 用户注册   POST  http://localhost:8080/api/v1/users/register
  Headers:  Content-Type: application/json
  Body (raw / JSON):
    {
      "username": "alice",
      "password": "secret123",
      "email":    "alice@example.com",
      "phone":    "13800000000",
      "nickname": "Alice"
    }
  预期响应：HTTP 201 Created
    {
      "code": 200,
      "message": "注册成功",
      "data": { "id": 1, "username": "alice", "email": "alice@example.com", ... }
    }
  数据库验证：SELECT * FROM users; 可以看到新插入的记录。

【接口 2】 获取所有书籍   GET  http://localhost:8080/api/v1/books
  无需 Body
  预期响应：HTTP 200 OK
    {
      "code": 200,
      "message": "success",
      "data": [ { "id":1, "title":"百年孤独", ... }, ... 共 8 条 ]
    }

【接口 3】 获取单本书籍   GET  http://localhost:8080/api/v1/book/4
  无需 Body
  预期响应：HTTP 200 OK
    {
      "code": 200,
      "message": "success",
      "data": { "id":4, "title":"三体（全集）", "author":"刘慈欣", ... }
    }
  错误用例：GET /api/v1/book/9999 → HTTP 400 + {"code":404,"message":"书籍不存在: id=9999"}
