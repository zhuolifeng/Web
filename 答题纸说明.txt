一、本次改造的核心目标（对照评分标准）
================================================================

A. Spring Boot 工程结构合理，**新增 DTO 层** 对 Repository 层进行封装。  1.5 分
B. 三个核心 API 全部通过 **Spring Data JPA** 读写数据库。                每个 1.5 分，共 4.5 分
   1) POST /api/v1/users/register       —— 用户注册
   2) GET  /api/v1/books                —— 书籍列表
   3) GET  /api/v1/book/{id}            —— 单本书籍详情

API 路径与请求/响应字段相对“迭代 2”完全保持不变（向前兼容前端）。

二、改造前 vs 改造后（关键差异）
================================================================

┌────────────────┬───────────────────────────────┬───────────────────────────────────────┐
│   层           │   改造前（迭代 2）            │   改造后（本次提交）                  │
├────────────────┼───────────────────────────────┼───────────────────────────────────────┤
│ Repository     │ extends JpaRepository         │ 同上 + 派生查询/@Query 方法           │
│                │                               │ (findByCategory/searchByKeyword 等)   │
├────────────────┼───────────────────────────────┼───────────────────────────────────────┤
│ Service        │ 返回 Entity (User / Book)     │ **统一返回 DTO** (UserDto / BookDto)  │
│                │                               │ Entity 仅在 service.impl 内部出现     │
├────────────────┼───────────────────────────────┼───────────────────────────────────────┤
│ Controller     │ 直接把 Entity 序列化给前端    │ 只与 DTO 通信，不感知存储实现         │
├────────────────┼───────────────────────────────┼───────────────────────────────────────┤
│ DTO 层         │ 仅有入参 DTO                  │ **新增出参 DTO**：UserDto / BookDto   │
│                │ (UserRegisterRequest 等)      │ 提供 from(Entity) 静态工厂            │
└────────────────┴───────────────────────────────┴───────────────────────────────────────┘

“出参 DTO” 是这次改造的核心，意义有三：

  1) **屏蔽数据源**：无论底层是 MySQL / MongoDB / Redis，Controller 与前端只看到
     稳定的 BookDto / UserDto 字段，未来切换存储只需新增 from(xxxEntity)，
     不会污染上层；
  2) **安全**：UserDto 默认不暴露 password 字段，避免把 BCrypt 密文返回给前端；
  3) **解耦**：JPA Entity 上的 @OneToMany、懒加载等持久化细节不会通过 JSON
     序列化泄漏出去（不再出现 LazyInitializationException 之类的问题）。

四、Spring Boot 工程的分层与请求流转
================================================================

           HTTP 请求 (浏览器 / Postman)
                       │
                       ▼
  ┌──────────────────────────────────────────────┐
  │  Controller 表现层（@RestController）        │
  │    UserController / BookController …         │
  │    —— 只依赖 DTO，不感知 Entity              │
  └──────────────────────────────────────────────┘
                       │ 调用业务方法
                       ▼
  ┌──────────────────────────────────────────────┐
  │  Service 业务层（接口 + 实现分离）           │
  │    interface UserService / BookService …     │
  │    impl/   ↔ 处理事务、规则；做 Entity↔DTO   │
  │            转换（UserDto.from(user) 等）     │
  └──────────────────────────────────────────────┘
                       │ 调用 Repository
                       ▼
  ┌──────────────────────────────────────────────┐
  │  Repository 数据访问层（Spring Data JPA）    │
  │    UserRepository extends                    │
  │        JpaRepository<User, Long>             │
  │    BookRepository extends                    │
  │        JpaRepository<Book, Long>             │
  │      + findByCategory / searchByKeyword …    │
  └──────────────────────────────────────────────┘
                       │ ORM 映射 (Hibernate)
                       ▼
  ┌──────────────────────────────────────────────┐
  │  Entity 实体层（@Entity + @Table）           │
  │    User (users 表) / Book (books 表) …       │
  └──────────────────────────────────────────────┘
                       │ JDBC
                       ▼
                   MySQL  (bookstore)

横切层：
  • dto/         —— ★ 出/入参 DTO（含本次新增 UserDto / BookDto）
  • exception/   —— BusinessException + @RestControllerAdvice 全局异常
  • config/      —— WebConfig 配置 CORS，允许前端 :3000 调用后端 :8080
  • security/    —— JWT 拦截器，保护非公开 API

五、关键代码片段（说明 JPA + DTO 的协作方式）
================================================================

★ 5.1  Repository（Spring Data JPA，无需手写 SQL）

    @Repository
    public interface UserRepository extends JpaRepository<User, Long> {
        Optional<User> findByUsername(String username);
        Optional<User> findByEmail(String email);
        boolean existsByUsername(String username);
        boolean existsByEmail(String email);
    }

    @Repository
    public interface BookRepository extends JpaRepository<Book, Long> {
        List<Book> findByCategory(String category);
        List<Book> findByAuthorContaining(String kw);

        @Query("SELECT b FROM Book b WHERE " +
               "LOWER(b.title)    LIKE LOWER(CONCAT('%', :kw, '%')) OR " +
               "LOWER(b.author)   LIKE LOWER(CONCAT('%', :kw, '%')) OR " +
               "LOWER(b.category) LIKE LOWER(CONCAT('%', :kw, '%'))")
        List<Book> searchByKeyword(@Param("kw") String keyword);
    }


★ 5.2  DTO（屏蔽 Entity，提供 from() 静态工厂）

    public class BookDto {
        private Long id; private String title; private String author; ...
        public static BookDto from(Book book) {
            BookDto dto = new BookDto();
            dto.id = book.getId();
            dto.title = book.getTitle();
            ...
            return dto;
        }
        // getters / setters ...
    }

    public class UserDto {
        // ★ 不包含 password 字段
        private Long id; private String username; private String email; ...
        public static UserDto from(User user) { ... }
    }


★ 5.3  Service 实现（JPA 查 → DTO 转 → 上抛）

    @Service @Transactional(readOnly = true)
    public class BookServiceImpl implements BookService {
        private final BookRepository bookRepository;
        public List<BookDto> listAll() {
            return bookRepository.findAll().stream()
                    .map(BookDto::from)
                    .toList();
        }
        public BookDto getById(Long id) {
            return bookRepository.findById(id)
                    .map(BookDto::from)
                    .orElseThrow(() -> new BusinessException(404, "书籍不存在: id=" + id));
        }
    }

    @Service
    public class UserServiceImpl implements UserService {
        @Transactional
        public UserDto register(UserRegisterRequest req) {
            if (userRepository.existsByUsername(req.getUsername())) {
                throw new BusinessException(409, "用户名已存在");
            }
            ...
            User user = new User();   // 构造 Entity
            user.setUsername(req.getUsername());
            user.setPassword(passwordEncoder.encode(req.getPassword()));
            ...
            return UserDto.from(userRepository.save(user));  // ★ 返回 DTO
        }
    }


★ 5.4  Controller（只依赖 DTO）

    @RestController @RequestMapping("/api/v1")
    public class BookController {
        @GetMapping("/books")
        public ApiResponse<List<BookDto>> listAll() {
            return ApiResponse.ok(bookService.listAll());
        }
        @GetMapping("/book/{id}")
        public ApiResponse<BookDto> getOne(@PathVariable Long id) {
            return ApiResponse.ok(bookService.getById(id));
        }
    }

    @RestController @RequestMapping("/api/v1/users")
    public class UserController {
        @PostMapping("/register")
        public ResponseEntity<ApiResponse<LoginResponse>> register(
                @Valid @RequestBody UserRegisterRequest request, ...) {
            UserDto saved = userService.register(request);            // ★ DTO
            LoginResponse resp = new LoginResponse(
                    null, saved.getId(), saved.getUsername(),
                    saved.getEmail(), saved.getNickname(), saved.getRole());
            return ResponseEntity.status(HttpStatus.CREATED)
                    .body(ApiResponse.ok("注册成功", resp));
        }
    }

六、数据库设计（不变）
================================================================

数据库：bookstore  (CHARSET=utf8mb4)

users 表：
    id           BIGINT  PK auto_increment
    username     VARCHAR(64)   UNIQUE NOT NULL
    password     VARCHAR(128)  NOT NULL
    email        VARCHAR(128)  UNIQUE
    phone        VARCHAR(32)
    nickname     VARCHAR(64)
    role         VARCHAR(32)
    created_at   DATETIME

books 表：
    id              BIGINT  PK auto_increment
    title, author, category, badge, stars
    rating_num, rating_count
    price, original_price
    description, intro, author_bio  (TEXT)
    publisher, publish_date, pages, isbn, binding
    cover_img, cover_emoji

application.properties 中 spring.jpa.hibernate.ddl-auto=update，
启动时 Hibernate 会自动校对表结构，schema.sql / data.sql 用于初始化数据。

七、启动步骤
================================================================

1) 启动 MySQL，并执行：
       CREATE DATABASE IF NOT EXISTS bookstore DEFAULT CHARACTER SET utf8mb4;

2) 修改 backend/src/main/resources/application.properties 中：
       spring.datasource.username=你的用户名
       spring.datasource.password=你的密码

3) 启动后端：
       cd backend
       mvn spring-boot:run
   监听 http://localhost:8080

4) （可选）启动前端：
       cd frontend
       npm install
       npm start
   访问 http://localhost:3000

八、Postman 测试用例
================================================================

【接口 1】 用户注册   POST  http://localhost:8080/api/v1/users/register
  Headers:  Content-Type: application/json
  Body (raw / JSON):
    {
      "username": "alice",
      "password": "secret123",
      "email":    "alice@example.com",
      "phone":    "13800000000",
      "nickname": "Alice"
    }
  预期响应：HTTP 201 Created
    {
      "code": 200,
      "message": "注册成功",
      "data": {
        "token":   null,
        "id":      2,
        "username":"alice",
        "email":   "alice@example.com",
        "nickname":"Alice",
        "role":    "USER"
      }
    }
  数据库验证：SELECT id, username, email FROM users; 能看到新插入的 alice 记录。

  ⚠️ 同样的请求第二次发送会得到 HTTP 4xx + {"code":409,"message":"用户名已存在"}
     —— 证明 Service 层走的是 UserRepository.existsByUsername 这条 JPA 派生查询。


【接口 2】 获取所有书籍   GET  http://localhost:8080/api/v1/books
  无需 Body
  预期响应：HTTP 200 OK
    {
      "code": 200,
      "message": "success",
      "data": [
        { "id":1, "title":"百年孤独", "author":"加西亚·马尔克斯", "category":"文学小说", ... },

        ...   共 8 条

【接口 3】 获取单本书籍   GET  http://localhost:8080/api/v1/book/4
  无需 Body
  预期响应：HTTP 200 OK

      "code": 200,

    }
  错误用例：GET /api/v1/book/9999 → HTTP 4xx + {"code":404,"message":"书籍不存在: id=9999"}
